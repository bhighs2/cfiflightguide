# 17. Kneeboard Planning

The kneeboard is abbreviated and must use the approved Flight Guide **HTML vertical-rail architecture**, not plain Markdown section headings.

Use the most recently approved lesson kneeboard as the structural reference.

## Section Rails

Use only those needed, but preserve the actual flight sequence.

Typical rails:

- PREFLT
- START/TAXI
- SURFACE when applicable
- RADIO when communications are a major lesson element
- BEFORE T/O
- AIR WORK
- RETURN

For a GROUND + FLIGHT lesson with airborne training, `AIR WORK` should normally be present.

# 19. Final Instruction to the Lesson Author / AI

Once status is **READY TO GENERATE**:

Generate one complete `lesson.md` using the Flight Guide Lesson Build Protocol and the approved source-alignment worksheet.
